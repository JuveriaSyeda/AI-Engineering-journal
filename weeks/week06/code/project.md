# Mini Project — Webpage Scraper using Ollama

## Built a simple webpage scraper project using Ollama.

`Tried`

- Extracted webpage content
- Tested multiple local models
- Compared response quality and speed

`Models Experimented With`

- Llama
- Mistral
- Gemma

`Learnings`

- Different models behave differently for the same prompt
- Smaller models are faster
- Larger models generally produce better reasoning
- Prompt clarity significantly affects output quality
